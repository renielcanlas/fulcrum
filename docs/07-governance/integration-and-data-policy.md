# Integration and data policy

Jira is authoritative for the underlying business initiative and collaboration artifacts; FULCRUM is authoritative for governed FCRM assessment and decision lineage. No automatic Jira issue creation is enabled. FULCRUM stores Jira correlation/sync metadata and selected evidence metadata or snapshots only where governance, performance, or historical replay requires it. Enterprise systems are integration candidates, not assumed dependencies. Demo adapters use synthetic data and are clearly labeled; production integrations require an approved data owner, identity scope, retention/classification review, provenance, retries, monitoring, and a rollback plan.
