# Architecture decision records

ADRs record significant decisions with Context, Decision Drivers, Options Considered, Decision, Rationale, Consequences, Production Evolution, and Related Decisions. Status vocabulary is `Proposed`, `Accepted`, `Superseded`, or `Deprecated`. ADR-000 through ADR-023 are accepted supporting records; [ADR-023](ADR-023-consolidated-architecture-baseline.md) is the accepted consolidation baseline; [ADR-024](ADR-024-initiative-as-primary-domain-object.md) locks Initiative as the primary domain object; [ADR-025](ADR-025-canonical-golden-initiative-fixture.md) locks the canonical synthetic demo fixture; [ADR-026](ADR-026-azure-ai-foundry-and-document-intelligence.md) establishes Azure AI Foundry and Document Intelligence as the primary AI platform direction; [ADR-027](ADR-027-version-binding-and-configuration-lifecycle.md) establishes immutable assessment bindings and governed configuration lifecycle; [ADR-028](ADR-028-jira-fulcrum-data-authority.md) establishes the Jira/FULCRUM authority boundary; [ADR-029](ADR-029-data-model-resolution.md) resolves the canonical vocabulary and compact physical schema boundary; [ADR-030](ADR-030-ai-capability-boundary.md) locks the AI, deterministic, and human responsibility boundary; [ADR-031](ADR-031-agent-and-orchestration-boundary.md) locks bounded orchestration and rejects unnecessary autonomous agents; [ADR-032](ADR-032-context-engineering-and-rag-boundary.md) locks scoped context, retrieval, and citation boundaries; [ADR-033](ADR-033-agent-and-tool-contracts.md) locks structured task/tool contracts and validation; [ADR-034](ADR-034-ai-delivery-and-evaluation-guardrails.md) locks model routing, evaluation honesty, and red-team controls. No ADR was deleted; future replacements must mark the old record `Superseded` and link the replacement.
