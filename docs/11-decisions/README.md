# Architecture decision records

ADRs record significant decisions with Context, Decision Drivers, Options Considered, Decision, Rationale, Consequences, Production Evolution, and Related Decisions. Status vocabulary is `Proposed`, `Accepted`, `Superseded`, or `Deprecated`. ADR-000 through ADR-023 are accepted supporting records; [ADR-023](ADR-023-consolidated-architecture-baseline.md) is the accepted consolidation baseline; [ADR-024](ADR-024-initiative-as-primary-domain-object.md) locks Initiative as the primary domain object; [ADR-025](ADR-025-canonical-golden-initiative-fixture.md) locks the canonical synthetic demo fixture; [ADR-026](ADR-026-azure-ai-foundry-and-document-intelligence.md) establishes Azure AI Foundry and Document Intelligence as the primary AI platform direction. No ADR was deleted; future replacements must mark the old record `Superseded` and link the replacement.
