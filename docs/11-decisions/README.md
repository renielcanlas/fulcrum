# Architecture decision records

ADRs record significant decisions with Context, Decision Drivers, Options Considered, Decision, Rationale, Consequences, Production Evolution, and Related Decisions. Status vocabulary is `Proposed`, `Accepted`, `Superseded`, or `Deprecated`. ADR-000 through ADR-022 are accepted supporting records; [ADR-023](ADR-023-consolidated-architecture-baseline.md) is the accepted consolidation baseline. No ADR was deleted; future replacements must mark the old record `Superseded` and link the replacement.
