# Token-efficiency strategy

Route simple extraction/classification to fast Azure AI Foundry deployments; reserve stronger reasoning for synthesis/challenge. Retrieve only relevant, access-approved chunks; use structured intermediate artifacts, bounded prompts, caching keyed by source/version, and compact summaries with provenance. Cache Document Intelligence output and embeddings by document-version hash. Record input/output tokens, model/deployment, latency, cost, cache hits, and quality so savings cannot hide degraded grounding. Prefer deterministic code whenever no language uncertainty exists.
