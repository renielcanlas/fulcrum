# FULCRUM

Financial crime risk Unified Lifecycle & Risk Understanding Model: a governed workbench that takes a product or change request from intake to committee-ready assessment.

**The system prepares. Humans decide.** FULCRUM never automatically approves or rejects a change.

This repository currently contains the architecture and AI-native SDLC bootstrap; application implementation is intentionally not started. Begin with [AGENTS.md](AGENTS.md) and [the project charter](docs/00-context/project-charter.md).
